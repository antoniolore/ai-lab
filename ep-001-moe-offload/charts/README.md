# ep-001 — charts

`plot_charts.py` writes `claim-vs-reality.csv` and `mac-placements.csv` from `../results_summary.csv` and, if matplotlib is installed, draft SVGs (run from the episode folder: `python3 charts/plot_charts.py`). The charts published in the articles were designed separately from the same data.
